# Murojaat

Matnli va ovozli murojaatlarni shifokorga yuborish, holatini kuzatish va hal qilinmaguncha takroriy eslatmalar berish uchun web/PWA va Android APK loyihasi.

## Ishlash tartibi
Fuqaro matn yoki 60 soniyagacha ovozli murojaat yuboradi. Murojaat bazaga yoziladi va tanlangan shifokor kabinetida `Yangi` holatida paydo bo‘ladi. Shifokor `Jarayonda` yoki `Hal qilindi` holatini tanlaydi. Hal qilinmagan murojaatlar 15 daqiqalik interval bilan qayta eslatma navbatiga tushadi.

Web frontend PWA sifatida o‘rnatiladi. `android/` papkasi Android WebView ilovasi bo‘lib, GitHub Actions debug APK yaratadi.

Test shifokor: `vrach01`. Vaqtinchalik parolni ishga tushirgandan keyin almashtirish tavsiya etiladi.
